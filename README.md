# Get Next Line

Get Next Line is a project developed as part of the 42 curriculum that consists of
implementing a function capable of reading a file or file descriptor line by line.
The function returns one line at a time, including the newline character when present,
while preserving the remaining content for subsequent calls. This project focuses on file handling,
static variables, buffer management, and dynamic memory allocation in C.

**Technologies:** C, File I/O, Makefile, Git.
